# 機能仕様

## ページ構成

### 映像ページ

- URLは`/`とする。
- Three.jsのCanvasをウィンドウ全体へ表示する。
- MIDI読み込み中は中央へ状態を表示する。
- 右下へ現在BPMと拍数を表示できる。
- 設定UIは表示しない。

### 設定ページ

- URLは`/control.html`とする。
- 映像ページとは別タブまたは別ウィンドウで開く。
- 設定変更を保存し、映像ページへ即時通知する。
- 映像ページを開くリンクを持つ。
- HTMLと狭幅表示では、ファイル、ロングトーンエフェクト、カスタムエフェクト、レベルメータの順で常時表示する。
- PC表示では、1行目をファイルとロングトーンエフェクト、2行目をレベルメータとカスタムエフェクトとする。
- ノート、ガイド、エフェクト、カメラ、再生は、1つの`details`内へまとめる。
- PCの詳細設定ではノートを左列の2行へSpanし、右列へガイドとエフェクトを縦に配置する。3行目はカメラと再生を横並びにする。
- ノートカテゴリーには通常ノート設定とロングトーンFade設定を配置する。
- 同じGrid行の設定カードは従来どおり行の高さへ合わせて伸長する。
- 詳細設定は初期状態を閉じ、開閉状態は保存しない。

## MIDI読み込み

- 起動時に設定中のMIDIファイル名を`public`直下から自動取得する。
- 初期値は`input.mid`とする。
- 拡張子がない場合は`.mid`を補完し、Pathが入力された場合は末尾のファイル名だけを使用する。
- `fetch`へ時刻クエリを付け、`cache: 'no-store'`を指定する。
- ローカルファイル選択UIは持たない。
- ノートが存在しないSMFはエラーとする。

## 再読み込み

### 映像ページ

- `R`でMIDIを再読み込みする。
- 再読み込み時にMIDIモデル、Timeline、描画オブジェクト、カメラ初期位置を再構築する。

### 設定ページ

- 「MIDIを再読み込み」ボタンから、正規化したファイル名とともに映像ページへ要求を送信する。
- 映像ページで読み込みが成功した後、設定ページへ完了メッセージを返す。
- 成功時は実際のファイル名を含めてalertする。
- 失敗時は理由を含むalertを表示する。

## 再生

### 初期状態

- 現在時刻は`-preRollSeconds`とする。
- 未来のノートと小節枠は、この時点から見える。

### 再生開始

- `Space`で常にプリロール先頭から再生する。
- 再生中に`Space`を押した場合も先頭からやり直す。
- 一時停止や現在位置からの再開は行わない。

### 停止

- `Esc`で再生を停止する。
- 現在時刻をプリロール先頭へ戻す。

### 曲末

- 曲長は最後のノートのNote Off時刻とする。
- 最後のノート終了後も`postRollSeconds`だけ時刻を進める。
- ポストロール終了後は停止し、最終フレームを保持する。
- 自動ループや自動巻き戻しは行わない。

### 時刻精度

- `performance.now()`から経過秒を算出する。
- `requestAnimationFrame`の回数を音楽時間として使用しない。
- 長いフレーム間隔が発生しても音楽時間を遅らせない。

## 発音エフェクト

- Note On通過時に、コアフラッシュ、拡散リング、少量のスパークを発音平面上へ生成する。
- 3種類は個別にON/OFFでき、既存のノート発光・残光を変更しない。
- 組み込みTextureは`public/assets/flare.png`、`ring.png`、`spark.png`とする。
- カスタム画像は`public`直下から読み込み、初期値を`custom.png`とする。
- カスタム画像名に拡張子がない場合は`.png`を補完する。
- 全エフェクトはTrack色とVelocityによる強度補正を使用する。
- 拡散リング、スパーク、カスタム画像には、設定から変換した演出用Velocityを使用する。
- コアフラッシュにはMIDIのVelocityをそのまま使用する。
- 組み込み3種は加算合成、カスタム画像は通常のAlpha Blendとする。
- カスタム画像はNote On時を最大濃度とし、時間経過でフェードしながら拡大または縮小する。
- 同じTrack・Pitch位置にカスタム画像が残っている場合は、旧画像を即座に破棄して最新のNote Onだけを表示する。
- エフェクト時間は曲時刻で進み、停止中は進めない。

### 演出用Velocity

- `effectVelocityEmphasisPercent`を`0〜200%`、`effectVelocityCharacteristicPercent`を`0〜100%`、`effectVelocityThresholdPercent`を`20〜80%`へ制限する。
- 入力Velocityは`0〜1`へ制限し、変換結果は`0〜2`とする。
- 強調が`0〜100%`の場合、入力`0`の出力を`1 - 強調率`、入力`1`の出力を`1`とする。
- 強調が`100〜200%`の場合、入力`0`の出力を`0`、入力`1`の出力を強調率とする。
- Middleは`(最大 - 最小) * 強調特性 + 最小`とする。
- 強調閾値は、出力がMiddleになる入力値を決める。初期値`50%`では入力`0.5`、`25%`では入力`0.25`、`75%`では入力`0.75`がMiddleになる。
- 入力`0〜強調閾値`と`強調閾値〜1`は、それぞれ最小・Middle・最大の間を線形補間する。
- 初期値`100% / 50% / 50%`は`0〜1`を変換しない。
- 設定変更後に生成する拡散リング、スパーク、カスタム画像から反映し、すでに生成済みのエフェクトは変更しない。

## ノート基本発光

- 未発音ノートのEmissive強度へ`noteBaseEmissiveIntensity`を使用する。
- 発音中と残光中もこの値を最低Emissive強度として保証する。
- ノート自体の最低発光量を調整するための値であり、距離によるFogの影響は変更しない。
- ノート以外の背景、枠、発音エフェクトの明るさは変更しない。

## 遠方視認性

- `distanceVisibility`で、ノートとTrackレベルメータに適用するScene Fogの影響を弱める。
- `0`では通常どおりScene Fogを適用し、`1`では対象へのFogを完全に除外する。
- Fog適用前後の色をShader内で補間し、近距離表示の明るさを増やさずに遠方の色を保つ。
- 背景と枠のFogには影響しない。
- Note Onエフェクト4種とロングトーン粒子はMaterialのFogを常に無効化しているため、`distanceVisibility`の影響を受けない。
- Note Onエフェクト4種はworld space基準のScaleを維持し、距離による見かけのサイズ変化は残す。

## ロングトーンFade

- `longNoteFadeEnabled`がONの場合、Note Onからの経過拍数でロングトーンを判定する。
- ノート長が`longNoteFadeStartBeats`を超えるノートだけを対象とする。
- 初期値では2拍目からノート本体とGlowのFadeを開始し、そこから6拍かけて完全に非表示にする。
- Fade完了拍は`min(longNoteFadeStartBeats + longNoteFadeDurationBeats, ノート長)`とし、Note Offより後までFadeを継続しない。
- Fade時間はFade開始位置からの相対拍数として設定し、Note Onからの絶対的な完全消失拍は設定しない。
- 一度対象になったノートは、Note Off後の通常残光へ遷移させない。
- 現在拍はTempo Map、PPQ、現在時刻からTickへ逆変換して求める。

### ロングトーン粒子化

- `showLongNoteDissolve`がONの場合、実際のFade区間内の`longNoteDissolveTimingPercent`位置で一度だけ粒子化する。
- 粒子化タイミングの初期値は`50%`とし、Fade区間の始端を`0%`、終端を`100%`として扱う。
- 実際のFade区間は、設定Fade時間とFade開始からNote Offまでの短い方とする。
- 粒子化成功時にノート本体とGlowを即座に非表示とし、以降は再表示しない。
- 粒子は残りの実Fade時間で拡散しながら完全に消える。
- 残り時間が`0.15秒`未満の場合、粒子化を省略して通常のFadeを継続する。
- `longNoteDissolvePreFlashSeconds`が`0`より大きい場合、粒子化の設定秒数前から発光を急速に強める。
- `longNoteDissolvePreFlashSeconds`が`0`の場合、事前発光を実行しない。
- 事前発光は粒子Textureが読込済みで、粒子表示に必要な残り時間を確保できる場合だけ実行する。
- 希望粒子化範囲はノート全長の`longNoteDissolveRangePercent`とし、初期値を`60%`とする。
- 範囲の奥端はNote Off位置と現在の表示最奥位置の近い方とする。
- 範囲の手前端はNote On位置より前へ出さず、発音平面では切り詰めない。
- 粒子位置は区間を均等分割したうえで、各区画内をランダム化する。
- 密度は1拍あたり6粒とし、1ノート最大粒子数は`longNoteDissolveMaxParticlesPerNote`で設定する。初期値は32粒とする。
- 全Active Burst合計は最大512粒とし、設定値が大きい場合もこの全体上限を優先する。
- 長い範囲では最大粒子数を維持して配置間隔を広げ、短い範囲では密度を維持して粒子数を減らす。
- 組み込みTextureは`public/assets/spark.png`を再利用する。

## Trackレベルメータ

- ノートを持つTrackごとに、発音平面下端から上へ伸びるレベルメータを表示する。
- 1Trackを20個の横長矩形セグメントで構成する。
- 感度`0%`では下から14個を低域、次の4個を中域、上の2個を高域とする。
- 感度`100%`では下から6個を低域、次の8個を中域、上の6個を高域とする。
- 感度の中間値では各Zone境界を線形補間し、最も近いセグメント位置へ丸める。
- Note OnのVelocityを正規化した値で、下から点灯するセグメント数を決定する。
- 同一フレーム内で同じTrackに複数のNote Onがある場合は最大Velocityを使用する。
- Note OffとDurationは参照しない。
- Note Onで現在値以上のVelocityへ即座に上昇し、`80ms`保持した後、`520ms`でゼロまで線形減衰する。
- 減衰中に現在値より低いVelocityを受けても、現在の減衰を急に下げない。
- 曲時刻が巻き戻った場合は全Trackをゼロへ戻す。
- Planeは発音平面と同じXY方向へ固定し、カメラ方向へ回転させない。
- `levelMeterDepthOffset`で、発音平面から時間軸の奥方向へ`0〜40 world units`移動できる。
- 奥行き位置を変更しても、メータが反応する時刻はNote On通過時のままとする。
- 低・中・高のセグメントは3つの`InstancedMesh`へまとめる。

### 色と不透明度

- Normalは低域を緑、中域を黄、高域を赤とする。
- 白系、青系、Trackカラーは全域で同系色を使用する。
- 低・中・高のOpacity比率はそれぞれ`0.4`、`0.7`、`1.0`とする。
- 実際のOpacityは各比率へ`levelMeterOpacity`を乗じる。

### 感度

- `levelMeterSensitivity`は`0〜100%`とする。
- 感度は点灯数やVelocity自体を増幅せず、低・中・高のZone境界だけを変更する。
- 低域終端はindex `14`から`6`へ線形に移動する。
- 中域終端はindex `18`から`14`へ線形に移動する。
- 低域から減った最大8セグメントを、中域と高域へ最大4セグメントずつ割り当てる。

## BPM表示

- 表記は`BPM = n`とする。
- Tempoイベントが変わる時刻で表示値を更新する。
- 小数BPMは小数第2位まで表示し、末尾の不要な`0`を除去する。
- Tempoイベントがない区間の初期値は`120`とする。
- プリロール中は曲頭時点のBPMを表示する。
- ポストロール中は最後のBPMを表示する。

## 拍数表示

- 表記は`現在拍 / 総拍数`とする。
- プリロール中は`0 / 総拍数`とする。
- 曲の開始時刻から1拍目とする。
- ポストロール中は`総拍数 / 総拍数`とする。
- 先頭Time SignatureとPPQから拍境界を計算する。
- 総拍数の桁数を基準に表示領域を固定し、現在拍の桁数が変化しても位置を動かさない。
- BPM欄も固定幅とし、拍数欄の左隣へ配置する。

## カメラ操作

| キー | 動作 |
|---|---|
| `←` / `→` | 水平角を変更 |
| `↑` / `↓` | 垂直角を変更 |
| `W` | 注視点との距離を縮める |
| `S` | 注視点との距離を広げる |
| `0` | 初期角度と初期距離へ戻す |

- キーを押している間、連続的に操作する。
- フレーム時間を使って移動量を計算する。
- タブが非アクティブになった場合は押下状態を破棄する。
- ページとMIDIの再読み込み時に初期位置へ戻す。
- 再生、停止、通常の設定変更では現在位置を維持する。
- カメラ位置は保存しない。

詳細な座標と制限は[`04-visual-spec.md`](04-visual-spec.md)を参照してください。

## 設定

- 初期設定はTypeScriptへ埋め込む。
- 変更値は`localStorage`へ保存する。
- 保存キーは`midi2visual.settings.v2`とする。
- 保存値のうち、現在の`AppSettings`に存在するキーだけを初期値へマージする。
- 廃止済みまたは未知のキーは無視し、旧キーから現行キーへの移行は行わない。
- 不正な保存値は破棄し、初期値を使用する。
- 「初期設定へ戻す」で全項目を初期化する。

## ページ間通信

- チャネル名は`midi2visual`とする。
- `BroadcastChannel`を使用する。
- メッセージは次の4種類とする。

| 種類 | 方向 | 用途 |
|---|---|---|
| `settingsChanged` | 設定→映像 | 設定の即時反映 |
| `reloadMidi` | 設定→映像 | MIDI再読み込み要求 |
| `midiReloaded` | 映像→設定 | 再読み込み成功 |
| `midiReloadFailed` | 映像→設定 | 再読み込み失敗 |

`storage`イベントも監視し、別ページで保存値が変わった場合の補助同期に使用する。

## エラー処理

- MIDIのHTTP取得失敗はHTTPステータスを含むエラーとする。
- ノートがないSMFは明示的なエラーとする。
- 映像ページは読み込み失敗時に中央表示とalertを出す。
- 詳細なエラーはDevTools Consoleへ出力する。
