# 機能仕様

## ページ構成

### 映像ページ

- URLは`/`とする。
- Three.jsのCanvasをウィンドウ全体へ表示する。
- MIDI読み込み中は中央へ状態を表示する。
- 右下へ現在BPMと拍数を表示できる。
- 設定UIは表示しない。

### 設定ページ

- URLは`/control.html`とする。
- 映像ページとは別タブまたは別ウィンドウで開く。
- 設定変更を保存し、映像ページへ即時通知する。
- 映像ページを開くリンクを持つ。

## MIDI読み込み

- 起動時に設定中のMIDIファイル名を`public`直下から自動取得する。
- 初期値は`input.mid`とする。
- 拡張子がない場合は`.mid`を補完し、Pathが入力された場合は末尾のファイル名だけを使用する。
- `fetch`へ時刻クエリを付け、`cache: 'no-store'`を指定する。
- ローカルファイル選択UIは持たない。
- ノートが存在しないSMFはエラーとする。

## 再読み込み

### 映像ページ

- `R`でMIDIを再読み込みする。
- 再読み込み時にMIDIモデル、Timeline、描画オブジェクト、カメラ初期位置を再構築する。

### 設定ページ

- 「MIDIを再読み込み」ボタンから、正規化したファイル名とともに映像ページへ要求を送信する。
- 映像ページで読み込みが成功した後、設定ページへ完了メッセージを返す。
- 成功時は実際のファイル名を含めてalertする。
- 失敗時は理由を含むalertを表示する。

## 再生

### 初期状態

- 現在時刻は`-preRollSeconds`とする。
- 未来のノートと小節枠は、この時点から見える。

### 再生開始

- `Space`で常にプリロール先頭から再生する。
- 再生中に`Space`を押した場合も先頭からやり直す。
- 一時停止や現在位置からの再開は行わない。

### 停止

- `Esc`で再生を停止する。
- 現在時刻をプリロール先頭へ戻す。

### 曲末

- 曲長は最後のノートのNote Off時刻とする。
- 最後のノート終了後も`postRollSeconds`だけ時刻を進める。
- ポストロール終了後は停止し、最終フレームを保持する。
- 自動ループや自動巻き戻しは行わない。

### 時刻精度

- `performance.now()`から経過秒を算出する。
- `requestAnimationFrame`の回数を音楽時間として使用しない。
- 長いフレーム間隔が発生しても音楽時間を遅らせない。

## 発音エフェクト

- Note On通過時に、コアフラッシュ、拡散リング、少量のスパークを発音平面上へ生成する。
- 3種類は個別にON/OFFでき、既存のノート発光・残光を変更しない。
- 組み込みTextureは`public/assets/flare.png`、`ring.png`、`spark.png`とする。
- カスタム画像は`public`直下から読み込み、初期値を`custom.png`とする。
- カスタム画像名に拡張子がない場合は`.png`を補完する。
- 全エフェクトはTrack色とVelocityによる強度補正を使用する。
- 組み込み3種は加算合成、カスタム画像は通常のAlpha Blendとする。
- カスタム画像はNote On時を最大濃度とし、時間経過でフェードしながら拡大または縮小する。
- 同じTrack・Pitch位置にカスタム画像が残っている場合は、旧画像を即座に破棄して最新のNote Onだけを表示する。
- エフェクト時間は曲時刻で進み、停止中は進めない。

## BPM表示

- 表記は`BPM = n`とする。
- Tempoイベントが変わる時刻で表示値を更新する。
- 小数BPMは小数第2位まで表示し、末尾の不要な`0`を除去する。
- Tempoイベントがない区間の初期値は`120`とする。
- プリロール中は曲頭時点のBPMを表示する。
- ポストロール中は最後のBPMを表示する。

## 拍数表示

- 表記は`現在拍 / 総拍数`とする。
- プリロール中は`0 / 総拍数`とする。
- 曲の開始時刻から1拍目とする。
- ポストロール中は`総拍数 / 総拍数`とする。
- 先頭Time SignatureとPPQから拍境界を計算する。
- 総拍数の桁数を基準に表示領域を固定し、現在拍の桁数が変化しても位置を動かさない。
- BPM欄も固定幅とし、拍数欄の左隣へ配置する。

## カメラ操作

| キー | 動作 |
|---|---|
| `←` / `→` | 水平角を変更 |
| `↑` / `↓` | 垂直角を変更 |
| `W` | 注視点との距離を縮める |
| `S` | 注視点との距離を広げる |
| `0` | 初期角度と初期距離へ戻す |

- キーを押している間、連続的に操作する。
- フレーム時間を使って移動量を計算する。
- タブが非アクティブになった場合は押下状態を破棄する。
- ページとMIDIの再読み込み時に初期位置へ戻す。
- 再生、停止、通常の設定変更では現在位置を維持する。
- カメラ位置は保存しない。

詳細な座標と制限は[`04-visual-spec.md`](04-visual-spec.md)を参照してください。

## 設定

- 初期設定はTypeScriptへ埋め込む。
- 変更値は`localStorage`へ保存する。
- 保存キーは`midi2visual.settings.v1`とする。
- 保存値を初期値へマージし、追加されたキーを補完する。
- 不正な保存値は破棄し、初期値を使用する。
- 「初期設定へ戻す」で全項目を初期化する。

## ページ間通信

- チャネル名は`midi2visual`とする。
- `BroadcastChannel`を使用する。
- メッセージは次の4種類とする。

| 種類 | 方向 | 用途 |
|---|---|---|
| `settingsChanged` | 設定→映像 | 設定の即時反映 |
| `reloadMidi` | 設定→映像 | MIDI再読み込み要求 |
| `midiReloaded` | 映像→設定 | 再読み込み成功 |
| `midiReloadFailed` | 映像→設定 | 再読み込み失敗 |

`storage`イベントも監視し、別ページで保存値が変わった場合の補助同期に使用する。

## エラー処理

- MIDIのHTTP取得失敗はHTTPステータスを含むエラーとする。
- ノートがないSMFは明示的なエラーとする。
- 映像ページは読み込み失敗時に中央表示とalertを出す。
- 詳細なエラーはDevTools Consoleへ出力する。
