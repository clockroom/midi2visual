# プロダクト仕様

## 目的

完成したDTM楽曲のSMFを、公開動画向けの映像としてリアルタイムに可視化します。

一般的なピアノロールやDAW画面をそのまま録画するのではなく、ノート、小節枠、発光、奥行き、カメラ構図を使った映像作品向けの表現を提供します。

## 想定利用者

- アプリの所有者本人
- ローカルのDocker環境を操作できる利用者
- SMFをDAW側で完成させてから可視化する利用者

配布用デスクトップアプリや一般利用者向けサービスは想定していません。ソースコードはパブリックリポジトリで公開できます。

## 基本ワークフロー

1. DAWからSMFを書き出す。
2. SMFを`public`直下へ配置し、必要に応じてカスタム画像も置く。
3. Docker上でVite開発サーバーを起動する。
4. 映像ページと設定ページを別タブまたは別ウィンドウで開く。
5. 設定ページでファイル名、構図、発音エフェクトを調整する。
6. 映像ページでカメラ位置を調整する。
7. `Space`で先頭から再生し、macOSのスクリーンキャプチャで録画する。
8. 動画編集ソフトで音声と映像を合成する。

## MVPの対象範囲

- `public`直下の設定可能なファイル名からのSMF読み込み
- Note On / Offを基礎とするノート描画
- Tempoに追従する実時間ベースの移動
- Track、Pitch、Timeによる3D配置
- 小節枠、拍枠、発音平面
- 発音時の発光とNote Off後の残光
- 発音面上のコアフラッシュ、拡散リング、スパーク
- Track色でAlpha Blendするユーザー画像
- Trackごとの20セグメント式Velocityレベルメータ
- 暗いグラデーション背景と少量の粒子
- キーボードによる再生、停止、カメラ操作
- 別ページから変更できる表示設定
- BPMと拍数の確認表示

## 対象外

### 音声

- MIDI音源
- ソフトウェアシンセ
- オーディオ再生
- 音声と映像の同期再生
- 音量、ミュート、ソロ

### 動画出力

- MP4、H.264、HEVCなどの動画エンコード
- 音声MUX
- オフラインレンダリング
- PNG連番出力

### MIDI編集

- ノートの追加、削除、移動
- VelocityやTempoの編集
- Track編集
- MIDIデバイス入力
- 録音

### 高度な解析

- コード、スケール、キーの判定
- フレーズ解析
- 自動演出生成

## 品質目標

- Firefoxを主対象として60fpsを目標にする。
- フレームレートに依存せず、実時間に追従する。
- 録画映像へ不要な操作UIを常時表示しない。
- ウィンドウサイズに応じて描画サイズとアスペクト比を更新する。
- 設定の試行錯誤を別ページから即座に確認できる。
